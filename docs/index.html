A logbook that stays on your phone

An offline Android logbook for fuel, running costs and maintenance reminders. Built in Kotlin and Jetpack Compose, with an amber instrument cluster that follows your phone's light or dark theme.

Download latest APK Android 8.0 or newer. Signed release, about 33 MB.

Private by design

  • No accountNothing to sign up for.
  • No analyticsNo tracking, no cloud, no automatic backup.
  • Online only on requestYour records stay on your phone. The app contacts GitHub only when you tap Check for updates, and your own Supabase project only if you set up the optional sync. Backups are CSV files you choose.

What it does

  • Trip computer: average consumption in L/100 km and km/L, cost per kilometer, monthly and yearly spending.
  • Receipt scan: a photo fills in liters, price, total and date. Recognition runs on the phone and the photo is deleted afterwards.
  • Full-to-full consumption: partial fill-ups between two full tanks count toward the same segment.
  • Range-based estimate: note the range shown before refueling and partial fill-ups get an estimate too.
  • Reminders: road tax, insurance, inspection and servicing, by date or kilometer threshold, with a daily local notification.
  • Home screen widget, multiple vehicles and a single-file CSV backup.

Install

  1. Download the APK on your phone with the button above.
  2. Open it and allow installs from your browser or file manager when Android asks.
  3. Later versions install over it without losing data.

Prefer automatic updates? Add https://github.com/FrancescoCastaldi/fuel-ledger-android to Obtainium.

Check the signature

Every release is signed with the same personal key. Android refuses an update signed with a different key. SHA-256 of the signing certificate:
