Fuel prediction and range telemetry engine, decoupled architecture and Room migration v6.

## Added

- **Fuel prediction engine:** calculates daily burn rate (km/day and liters/day), estimates empty date and remaining days of fuel, reserve threshold alerts (< 50 km), and range decay slope analysis.
- **Mid-tank telemetry checkpoints:** log current odometer and remaining range directly from the dashboard to track real-world consumption decay.
- **Compose fuel prediction card & dialog:** interactive `FuelPredictionCard` on Dashboard and `AddCheckpointDialog` for 1-tap logging.
- **Android Auto & Glance widget:** fuel runout days estimation displayed on Android Auto overview screen and Glance wide widget.
- **Room database migration 6:** `FuelCheckpoint` entity and `MIGRATION_5_6` with full migration test coverage.
- **Backup & sync support:** CSV type 'C' record support and Supabase cloud sync for telemetry checkpoints.

## Changed

- **Decoupled architecture:** `CarRepository` decoupled into domain repository interfaces (`domain/repository/`) with dedicated Room implementations and composite facade.
- **Pure Kotlin UseCases:** business logic orchestrated by domain use cases with zero framework coupling.
- **UDF/MVI ViewModels:** all 10 ViewModels refactored with immutable `UiState`, `UiAction`, and buffered `UiEvent` channels.

## Upgrading

- Install over 0.11.1 with **Settings > Updates > Check for updates**. Your records and database are migrated automatically to version 6.
