Receipt scanning, a home screen widget and the first signed release.

## New

- **Scan receipt:** in a new fill-up, take a photo or pick one from the gallery. Liters, price per liter, total and date are filled in for you. Recognition runs on the phone and the photo is deleted afterwards. Enter the odometer yourself and check the values before saving.
- **Home screen widget:** average consumption, odometer, the most urgent reminder and a **Fill-up** button that opens the form directly. Add it from your launcher's widget list ("Trip computer").

## Changed

- The APK contains ARM code only and is about 33 MB.
- Releases are signed with a personal key. See [installing and updating](https://github.com/FrancescoCastaldi/fuel-ledger-android/blob/main/docs/install.md).

## Before you install

If you have a local or debug build of Fuel Ledger, export a CSV backup from **Settings**, uninstall it, install this release and import the backup. Android cannot update a build signed with a different key.
