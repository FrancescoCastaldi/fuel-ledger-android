Km per day, salary cycles and a period filter for the statistics, plus the fix for cloud sync of fuel checkpoints.

## Added

- **Km per day:** the Dashboard shows the average over the last 30 days, and Statistics shows the average for the chosen period, from fill-ups and checkpoints.
- **Salary cycles:** spending runs from the 10th to the 9th of the next month. The Dashboard shows what you spent in the current cycle.
- **Statistics period filter:** current cycle, 3, 6 or 12 cycles, all time, or a custom date range.
- **Statistics charts:** spending per salary cycle, km per day and price per liter. All of them follow the period filter.

## Fixed

- **Cloud sync stopped at fuel checkpoints:** the cloud table lacked the deleted flag. Run the `alter table public.fuel_checkpoints` line from the "Upgrading to 0.12" section of `docs/supabase/schema.sql` once in your Supabase project.
- **Readable sync errors:** when the server refuses a write, the sync message now includes the server's reason.

## Upgrading

- Install over 0.12.0 with **Settings > Updates > Check for updates**. Your records are kept.
- If you use cloud sync, run the one-line schema change above before your first sync with 0.13.0.
