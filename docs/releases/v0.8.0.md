Updates from inside the app.

## New

- **Update app:** when a newer release exists, Settings > Updates > **Update app** downloads its APK inside the app, with a progress bar and a cancel button. You no longer land on a GitHub page and then fetch the file by hand.
- **Checked before it is offered:** the download is compared with the SHA-256 published for it by GitHub, and the package name, the version and the signing certificate must match this app. A file that fails any of these is deleted.
- **Handed to Android's installer:** the app opens the system confirmation for the update. Your records are kept, as before, because the signing key is the same.
- **Back from the permission screen:** the first time, Android asks you to allow installs from Fuel Ledger. The app opens that page and continues the update by itself when you come back.

## Installing 0.8.0

**0.8.0 is installed by hand, once.** The in-app update exists only from this version on. Download `FuelLedger-v0.8.0.apk` from the release page on your phone, open it, and allow installs from your browser or file manager when Android asks. From 0.8.1 on, updates are offered and installed from Settings.

Your data is kept. Exporting a CSV backup from **Settings** before updating is still a good habit.

## Privacy

The app still reaches the network only when you tap a button in Settings. **Update app** downloads one file from GitHub and sends nothing about you.

This release is signed with the same key as 0.3.0 to 0.7.0 and installs over them.
