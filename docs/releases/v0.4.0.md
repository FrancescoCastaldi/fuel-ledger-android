Consumption for partial fill-ups, estimated from the range your car shows before you refuel.

## New

- **Range before fill-up:** an optional field in the fill-up form. Note the range shown on the dashboard before refueling and Fuel Ledger estimates consumption between two fill-ups with a reading, partial ones included. The fill-up list shows it as `~6.1 L/100` when there is no exact full-to-full figure.
- **Estimated from range:** a new card in Statistics with the average estimate, the number of intervals and, once there are enough full tanks with a reading, how far your board computer is off. That figure is used to correct the estimates.
- **Download page:** [francescocastaldi.github.io/fuel-ledger-android](https://francescocastaldi.github.io/fuel-ledger-android/) always links to the latest APK.

## Changed

- The database moves to version 2. Your data is kept. Exporting a CSV backup from **Settings** before updating is still a good habit.
- The CSV backup carries the range in a new last column. Backups from earlier versions import normally, and older apps ignore the column.

## Updating

This release is signed with the same key as 0.3.0 and installs over it. If you have a debug or local build, export a CSV backup, uninstall it, install this release and import the backup: Android cannot update a build signed with a different key.
