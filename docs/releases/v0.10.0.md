Cloud attachments, keep-alive automation, and seasonal tire tracking.

## New

- **Cloud attachments:** save and attach receipt and invoice photos to refuels and expenses. Images are compressed locally and optionally synced to your private Supabase Storage bucket.
- **Supabase keep-alive:** scheduled automated workflow pings the project every 3 days to prevent inactivity pause on the free tier.
- **Seasonal tire tracking:** track kilometers driven on summer versus winter tires, with automated reminders for seasonal tire swaps.
- **Fiscal and mileage reports:** export aggregated vehicle expenses, fuel costs, and cost per kilometer to CSV for business reimbursements or tax records.
- **Periodic cloud sync:** optional background sync scheduled every 3 days on unmetered Wi-Fi.

## Changed

- The database moves to schema version 5: nullable `receiptPath` column added to refuels and expenses. Existing data is preserved.
- CSV backups and cloud rows support optional receipt paths with full backward compatibility.

## Upgrading

- Update from the app via Settings > Updates, or install the APK directly from GitHub Releases. Existing records and settings are kept.
- If using cloud sync, run the upgrade SQL lines in `docs/supabase/schema.sql` to create the storage bucket and columns.
